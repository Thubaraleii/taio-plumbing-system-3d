# Rasters geologicos auxiliares

Aqui entram rasters geofísicos/geologicos que possam ajudar a restringir o
modelo (ex.: magnetometria, se voce tiver dados aerogeofisicos da regiao de
Taio, mapas geologicos rasterizados, etc.). Nao sao obrigatorios para o
pipeline basico do GemPy — o essencial e a topografia (pasta
`topografia_drone/`) e os pontos estruturais (pasta `pontos_estruturais/`).
Use esta pasta conforme for precisando incorporar mais evidencias ao
modelo.
